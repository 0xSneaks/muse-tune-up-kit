# MEMORY.md — template (lean live layer)

Keep this file to current state + standing rules only. History belongs
in dated notes under `memory/`, pulled on demand. Nothing secret ever
goes in this file.

## The owner
- _Name, timezone, what they're building, how they work — from their
  own words, dated as learned._

## Hard rules
- _Standing orders, gates, and never-do items, each with the date the
  owner set it._

## Current state
- _What's live, what's in progress, what's parked — one line each,
  updated as things change, removed when they finish._
